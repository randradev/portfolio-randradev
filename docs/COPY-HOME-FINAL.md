- Directa, técnica, segura y concreta.

- Verbos claros: construir, desarrollar, integrar, automatizar.
- Full Stack como perfil principal; Python e IA aplicada como diferenciadores.
- El diseño aporta personalidad; el texto comunica capacidad.

### Evitar
- Esloganes publicitarios largos o grandilocuentes.
- Párrafos que expliquen demasiado.
- Adjetivos vacíos como “innovador”, “revolucionario” o “disruptivo”.
- Frases genéricas como “apasionado por la tecnología”.
- Afirmaciones de experiencia, resultados o dominio que no puedan demostrarse.
- Copy orientado a captar clientes freelance. El objetivo principal es conseguir empleo.
